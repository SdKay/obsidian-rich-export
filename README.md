The original plugin has not been maintained for a long time, so this repository continues it as a new project and is being developed further from here. Huge thanks to Nathan George and every contributor of the original plugin — this plugin would not exist without their years of work. The original MIT license and copyright notice are kept in [LICENSE](LICENSE).

Export your notes, canvases, or a whole vault to a static HTML website — or to one single HTML file. The exported pages keep the look of your vault and can be published anywhere. Part of the Rich plugin series alongside [Rich Table](https://github.com/SdKay/obsidian-rich-table), [Rich View](https://github.com/SdKay/obsidian-rich-view), [Rich Search](https://github.com/SdKay/obsidian-rich-search) and [Rich Property](https://github.com/SdKay/obsidian-rich-property).

---

## Features

- Export a single file, a selection of files, a canvas, or the whole vault
- Full text search
- File navigation tree and document outline
- Graph view and backlinks
- Light / dark theme toggle
- Optimized for web and mobile
- Works with many plugins (Dataview, Tasks, …)
- Option to export the HTML and all of its dependencies into one single file
- Headless export with Docker / GitHub Action

---

## Installation

**Manual:**

1. Download `main.js`, `manifest.json` and `styles.css` from the [latest release](https://github.com/SdKay/obsidian-rich-export/releases/latest)
2. Copy them to `<vault>/.obsidian/plugins/rich-export/`
3. Reload Obsidian and enable **Rich Export** in **Settings → Community plugins**

**Beta (via [BRAT](https://obsidian.md/plugins?id=obsidian42-brat)):** add `https://github.com/SdKay/obsidian-rich-export` as a beta plugin.

Minimum Obsidian version: **1.6.0**

---

## Usage

Click the ribbon icon, or run **Set html export settings** from the command palette, choose the files to export and the output folder, then adjust the options you need. **Export using previous settings** and **Export only current file using previous settings** repeat the last export without opening the dialog. Plugin settings are under **Settings → Rich Export**.
